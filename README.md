[Сервис "Валидация банковской карты"](https://divk-neto.github.io/HW_11-4_testing/)

**Сервис для проверки номера банковской карты.**  
Виджет определяет платёжную систему по первым цифрам, подсвечивает логотип, проверяет номер по алгоритму Луна и показывает результат в модальном окне. Проект выполнен с использованием современного инструментария: Webpack, Babel, Jest, Puppeteer, ESLint, Prettier, Husky и настроен автоматический деплой на GitHub Pages.
