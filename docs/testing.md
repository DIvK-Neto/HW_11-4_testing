
# Тестирование

В проекте используются три уровня тестов:
- модульные, 
- интеграционные (DOM), 
- и сквозные (e2e).

## Модульные тесты

Проверяют отдельные функции и классы:
- `validator.js` — алгоритм Луна.
- `cardTypeDetector.js` — определение платёжной системы.
- `CardManager.js` — рендеринг и подсветка логотипов.
- `Modal.js` — открытие/закрытие модального окна.

## Интеграционные тесты (JSDOM)

Тестируют взаимодействие с DOM:
- `widget.test.js` — проверка подсветки при вводе, появление модального окна и его закрытие.

## Сквозные тесты (Puppeteer)

Запускаются в отдельной задаче GitHub Actions и проверяют работу виджета в реальном браузере:
- Ввод валидного номера → ожидание сообщения "Номер карты валидный".
- Ввод невалидного номера → ожидание сообщения "Номер карты невалидный".


## Запуск тестов локально

* модульные и интеграционные тесты (без e2e)
    ```bash
    npm test 
    ```
* тесты с отчётом о покрытии
    ```bash
    npm run coverage 
    ```
* сквозные тесты (требуют собранного проекта)
    ```bash
    npm run test:e2e 
    ```
## Покрытие кода
Текущее покрытие поддерживается на уровне выше 95%. Отчёт можно посмотреть, выполнив `npm run coverage` и открыв `coverage/lcov-report/index.html`.
