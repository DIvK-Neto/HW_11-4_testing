# Установка и запуск

## Предварительные требования

- Node.js (версия 20 или выше)
- npm (или yarn)

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DIvK-Neto/HW_11-4_testing.git

   cd HW_11-4_testing
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
## Запуск в режиме разработки
1. Выполните команду:
   ```bash
   npm start
   ```


После запуска сервер будет доступен по адресу http://localhost:8080. При изменении файлов страница будет автоматически перезагружаться.


## Сборка для продакшна

1. Выполните команду:
    ```bash
   npm run build
   ```

Готовые файлы будут помещены в папку dist/. Их можно развернуть на любом статическом хостинге.

## Линтинг и форматирование
* Проверка кода линтером:
    ```
    npm run lint
    ```
* Автоматическое исправление ошибок линтинга:
    ```
    npm run lint:fix
    ```
* Форматирование кода с Prettier:
    ```
    npm run format
    ```
