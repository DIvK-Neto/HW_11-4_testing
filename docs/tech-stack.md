# Используемые технологии

## Основные инструменты

- **JavaScript (ES6+)** — основной язык разработки.
- **Webpack** — сборка модулей, обработка стилей и изображений.
- **Babel** — транспиляция современного JavaScript для поддержки старых браузеров.
- **CSS3** — стилизация, адаптивная вёрстка.

## Тестирование

- **Jest** — фреймворк для модульного и интеграционного тестирования.
- **jsdom** — эмуляция браузерного окружения в тестах.
- **Puppeteer** — управление браузером для сквозных тестов.

## Качество кода

- **ESLint** — статический анализ кода.
- **Prettier** — автоматическое форматирование.
- **Husky** + **lint-staged** — запуск линтера и форматтера перед коммитом.

## CI/CD и деплой

- **GitHub Actions** — автоматический запуск тестов и сборка при пуше.
- **GitHub Pages** — хостинг для демо-версии.
- **semantic-release** — автоматическое создание релизов и changelog при пуше в main.

## Дополнительно

- **.browserslistrc** — определение целевых браузеров.
- **.editorconfig** — единообразие настроек редактора.
